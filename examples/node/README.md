# 网页接入示例

需要 Node.js 22.13+。在本目录运行：

```bash
cp .env.example .env
npm ci
npm start
```

打开 http://localhost:3000，输入示例密码 `local-demo-password`。

默认使用演示套餐和模拟付款。接入自己的产品，请在[一人付官网](https://ai6666.com/opcpay/)创建项目、配置支付宝套餐并申请 API Key。

[接入教程](../../docs/quickstart.md) · [完整 API 文档](https://ai6666.com/opcpay/docs/)
