# 先跑通一个完整示例

## 1. 准备环境

SDK 支持 Node.js 18+。独立网页示例使用 Node.js 22.13+，通过内置 SQLite 保存会话、购买请求、核销意图和回执；不需要安装数据库服务器。Node 22 可能提示 SQLite 为实验功能，这是 Node 自身的提示。

```bash
git clone https://github.com/Yapie0/opcpay.git
cd opcpay/examples/node
cp .env.example .env
npm ci
npm start
```

打开 http://localhost:3000，输入 `.env` 中的示例密码；默认模拟密码为 `local-demo-password`。

## 2. 在模拟模式中体验

默认 `PAYMENT_MODE=mock`，不需要 API Key，不调用一人付或支付宝，不会真实收款。

1. 页面读取模拟接口返回的全部套餐，选择任意一个。
2. 点击购买后查看二维码弹窗，点击“模拟付款”。
3. 权益余额增加后，点击“生成示例报告”。每次消耗 1 次，重复发送同一次操作不会重复扣减或交付。
4. 刷新或重启后，记录仍保存在 `data/example.sqlite`。

模拟档位仅用于演示；真实模式读取 `/product` 返回的全部档位，没有写死“1次/400次”或真实价格。

## 3. 切换真实项目

先在 https://ai6666.com/opcpay/ 创建项目，完成支付宝配置并申请 API Key。修改本地 `.env`：

```dotenv
PAYMENT_MODE=live
DATABASE_PATH=./data/live.sqlite
opcpay_api_key=你的项目APIKey
PUBLIC_ORIGIN=https://你的示例站点域名
DEMO_PASSWORD=换成仅你自己知道的长密码
DEMO_USER_ID=example-user-1
```

模拟模式与真实模式必须使用不同的 `DATABASE_PATH`，不能将模拟购买或核销记录带到真实模式。已有未标记模式的旧示例数据库也应使用新路径；原文件保留不删除。

将域名 HTTPS 反向代理到此服务的 `127.0.0.1:3000`，代理保留 Host。`PUBLIC_ORIGIN` 只填协议和域名（可含端口），不加路径。回跳固定为 `/return`。主站 API 当前只允许项目官网相关域名作为回跳地址，请使用该项目实际配置的受信域名。

重启服务后，页面会明显显示“真实模式”；先确认套餐与价格。点击“购买”会生成真实购买入口，付款需要你在支付宝内确认。“生成示例报告”会真实消耗一个次数/积分单位。示例不会在加载页面或支付回跳时自动扣次。模拟付款入口在真实模式下不存在。

网页的“我已完成，查询权益”只检查当前权益，最多连续查询3次，不把回跳、扫码或余额增加标记为某一笔付款成功。要再次购买，可主动点击“新建购买”，旧入口不会自动取消。

## 4. 接进自己的产品

保留现有登录系统，从**服务端登录身份**取得稳定用户 ID。示例的单账号密码登录只是帮助你跑通流程，不能原样作为面向所有用户的账号体系。

| 示例位置 | 接入你的项目时替换什么 |
|---|---|
| `server.mjs` 的 session/login | 你已有的登录会话，不能接收客户端任意指定 userId |
| `store.mjs` | 应用自己的数据库和事务；业务操作号和回执应有唯一约束 |
| `/api/purchase` | 购买前保存用户、SKU、业务编号和回跳URL；价格从接口读取 |
| `/api/use` | 服务端计算额度，用核销结果控制你自己的业务 |
| `receipts` 事务 | 替换成同库业务交付；外部AI任务用唯一outbox/队列任务 |
| `public/` | 按自己产品的风格展示套餐、权益和购买入口 |

示例串行处理单用户操作，供单实例学习与验证使用；多实例生产服务要使用数据库行锁/唯一约束和持久任务队列，不能仅靠进程内的锁。

次数和积分模式均按服务端设置核销，本例每份报告消耗1个单位。买断、时长包则只在 `access_granted=true` 且 `decision=ALLOW` 时放行，不调用次数核销。模拟网页重点演示次数包；其他模式的服务端分支通过隔离测试覆盖，未声称完成每种模式的真实付款测试。

## 遇到问题

- 端口不是3000：同步修改 `.env` 的 `PORT` 和 `PUBLIC_ORIGIN`，浏览器访问相同地址。
- 使用 `127.0.0.1`：`PUBLIC_ORIGIN` 也要改成 `http://127.0.0.1:3000`；示例校验 Host/Origin，不混用两个地址。
- Key 不可用或未签约：先查 `capabilities()` / `product()`，确认实际项目状态。
- 返回后余额未增加：稍后查询权益，不重复付款；购买入口不证明单笔已付款。
- 使用结果待确认：点击“恢复上一次报告”，不能新建核销号再试。
- 额度已扣但交付出错：原号恢复交付，不能再扣一次。
- TypeScript：安装项目所用的 `@types/node`；包内声明会自动提供参数和返回值提示。

完整字段以 [在线文档](https://ai6666.com/opcpay/docs/) 为准。当前交易、退款和账单5个预留方法仍返回501；示例没有实现微信支付。
